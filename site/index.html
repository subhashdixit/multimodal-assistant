For documents, run OCR first. Qwen/SmolLM text models use recognized or pasted text, not the image. Experimental vision can describe pixels but may invent details; verify its output against the image.

Generate with a free open model · no API key

Download model weights from Hugging Face, then run inference on this device in a worker. Model-file requests expose normal network metadata; your prompt/image is not uploaded. A small model can invent facts and may fail to follow instructions. Check every result.

How this works · scope and limitations

Local extraction/retrieval is labelled separately from generative AI. Source IDs show where evidence came from; citations do not guarantee that a generated claim is correct. PDFs require selectable text; scanned pages need OCR. No imported document is persisted by this app.
